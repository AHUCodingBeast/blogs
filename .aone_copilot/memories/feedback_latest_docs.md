所有博客笔记的撰写必须严格基于最新版本的官方文档，禁止包含过时、已废弃或已被替代的技术内容。

**Why:** 用户在过往项目中观察到实际使用的技术栈与旧版文档描述不一致（如 bootstrap.yml 已被废弃），过时的内容会误导复习和面试准备，降低笔记的实际价值。

**How to apply:** 在撰写或修改任何技术笔记前，必须先查阅对应组件的最新官方文档确认当前推荐做法；对于版本迭代较快的组件（如 Spring Cloud Alibaba、Spring Boot），需明确标注适用版本号；发现已有笔记中存在过时内容时，应主动修正并标注变更说明。
